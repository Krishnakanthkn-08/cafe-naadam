# Café Naadam — Premium Mysuru Website

## Run
1. Open this folder in VS Code.
2. Keep `index.html` and the `assets` folder together.
3. Open `index.html` with VS Code Live Server, or double-click it in a browser.

## Included
- Premium Mysuru-inspired visual system
- Cinematic loading screen
- Fixed glass navigation
- Animated hero/orbit
- Scroll reveal animations
- Moving culture marquee
- Animated food/plate scene made with CSS
- Full menu based on the supplied menu-board images
- Responsive mobile layout
- Café Naadam logo from the supplied image

## Before publishing
Replace the Visit section's placeholder contact/reservation details with the restaurant's verified address, phone number, opening hours and booking link.
